### 2. Extraction

The intervention computes a prompt-normalized second moment and class mean for each KV head, projects the positive-minus-negative mean into the top-rank Gram eigenspace, then normalizes each head direction. Runtime uses:

> `projection = einsum(values, direction, "b h t d, k h d -> b h t k")`
>
> `delta = einsum(projection.abs() * magnitude.T[None, :, None, :], ...)`
>
> `return values + self._steering_coeff * delta`

Source: `src/steering_lite/variants/kv_cache_gram.py:89–101` in commit `ef26f16`.

The extraction demo confirms the intended prompt pairing: POS and NEG have the same generic suffix, while only the persona text differs. This verifies matched prompt construction, not the direction’s semantic content. Because all 200 suffixes were used, the eight calibration messages are also present in extraction content. Calibration is therefore not held out from the suffix corpus.

No run metric checks whether `c` separates unseen positive and negative prompts, whether projected contrast energy survives rank 16, or whether shuffled labels produce similar directions. The earliest unsupported mechanism link is therefore “the extracted per-head direction encodes the intended Care/Authority concept.”

## Ranked nonexclusive hypotheses

### H1 [method | Almost Certain | 90%]

- **Mechanism:** the rectified edit `V' = V + C|V·c|c` adds the same directional component regardless of the projection sign. Repeated across 21 layers and tokens, +C drives a broad response/category bias rather than a conditional concept edit.
- **Evidence:** +C selects `social` on 115/132 rows versus 33/132 bare, while ΔSocial is +7.800 and the first trace calls mockery “friendly or positive.”
- **Contrary evidence:** −C preserves a diverse category distribution and produces ΔCare +1.713, so the direction contains some behaviorally relevant structure.
- **Discriminating test:** from saved traces, compute transitions by true foundation. Generic bias predicts many unrelated foundations move to `social`; concept steering predicts concentration on authority/welfare conflicts. Then compare the same direction using a signed, bounded edit on a tiny set.
- **Fix/action:** do not tune rank first. Replace rectification only after the trace transition audit; prespecify how the revised edit should affect both projection signs.
- **Interpretability:** yes. This run credibly measures this exact rectified intervention at this operating point.

### H2 [data | Likely | 65%]

- **Mechanism:** the positive-minus-negative mean encodes the only changed text—the persona instruction and its contextual consequences—rather than the intended moral concept. Per-head normalization preserves weak/noisy heads.
- **Evidence:** the extraction demo uses identical suffixes and one persona pair; all 200 corpus entries are consumed. No held-out projection-separation or shuffled-label result exists.
- **Contrary evidence:** the persona demo generations discuss the intended authority/wellbeing distinction, and −C moves Care CLR upward.
- **Discriminating test:** measure held-out persona classification from cache projections, then repeat with shuffled labels. Real concept structure predicts a large held-out gap that disappears under shuffling.
- **Fix/action:** reserve a disjoint suffix split and weight or select heads by held-out contrast reliability instead of unit-normalizing every head.
- **Interpretability:** partial. Runtime behavior is interpretable; the learned direction’s semantic identity is not.

### H3 [measurement | Almost Certain | 95%]

- **Mechanism:** `mean_pmass_allowed` detects whether probability stays on allowed answer tokens, not whether reasoning preserves facts or task meaning. Its coherence multiplier therefore misses confident semantic collapse.
- **Evidence:** +C has answer-token mass 0.999998483 and margin 11.126, yet accuracy 0.242 and the first trace asserts that mockery is harmless.
- **Contrary evidence:** the metric correctly detects answer-format failures; no claim in its implementation says it measures factual fidelity.
- **Discriminating test:** blind-score a balanced sample for fact preservation and instruction comprehension, then compare those scores with answer-token mass.
- **Fix/action:** rename/report this component as answer-format mass and add a separate semantic-fidelity measure before calling a generation coherent.
- **Interpretability:** yes for token-format coherence; no for semantic coherence.

### H4 [harness | Highly Likely | 80%]

- **Mechanism:** +C is calibrated for 60 tokens, −C is not calibrated, and evaluation reasons for up to 256 tokens. Asymmetric accumulated drift can dominate the forced-choice result.
- **Evidence:** the log’s own expectation fails: p95 KL reaches 5.269 at t=40 and 4.634 at t=57. The sweep source evaluates −C at the same coefficient without recalibration.
- **Contrary evidence:** the final eight 60-token +C calibration snippets are readable, and the negative result is also visible in early reasoning.
- **Discriminating test:** measure both signs on unseen prompts for 256 tokens. If H4 dominates, the arms’ RMS/r4ms drift will diverge materially from 0.8 and from each other; if not, category bias remains at matched drift.
- **Fix/action:** calibrate signs separately or use an explicitly symmetric edit, and match the calibration horizon to evaluation.
- **Interpretability:** partial. The +C 60-token operating point is calibrated; bidirectional equal-KL claims are not.

### H5 [misconception | Almost Certain | 90%]

- **Mechanism:** centered forced-choice category evidence is described as moral wrongness/selectivity. A broad rise in the “not morally wrong” category necessarily lowers other category CLR values and can imitate foundation changes.
- **Evidence:** +C ΔSocial is +7.800 while Care, Authority, Sanctity, Loyalty and Fairness all decrease. The first +C output reinterprets the task, not a preference trade-off.
- **Contrary evidence:** the paired metric still correctly reports that +C and −C produce different response profiles; it is not numerically broken.
- **Discriminating test:** evaluate direct action/wrongness judgments on matched authority-vs-welfare conflicts and unrelated controls. Concept steering predicts selective preference changes without broad classifier-label collapse.
- **Fix/action:** narrow claims to category-attribution CLR; use a separate behavioral task for moral-priority claims.
- **Interpretability:** yes as a classifier-response result; no as an independent moral-wrongness effect.

### H6 [bug | Highly Unlikely | 15%]

- **Mechanism:** a real-model cache layout, layer selection, or edit-once error could create dose-responsive but wrong behavior despite unit tests.
- **Evidence:** no actual-run cache-equivalence trace or per-layer intervention norm was persisted.
- **Contrary evidence:** 46 tests pass; the run completes on the hybrid model; bare is exactly reproduced; the response is coefficient-dependent; a prior independent code review’s five cache lifecycle findings were fixed.
- **Discriminating test:** on the real model and one short prompt, compare zero-coefficient cache logits to bare, and compare one edited cache update against the formula tensor-by-tensor at selected layers.
- **Fix/action:** add that real-model smoke measurement before another expensive cache-method sweep.
- **Interpretability:** yes, with a small residual implementation-risk discount.

### What would change the verdict

A separately calibrated, long-horizon run would update toward success if both signs remain semantically grounded, move Care and Authority oppositely on direct conflict judgments, leave unrelated controls stable, and beat a same-cache random direction. It would update toward an implementation bug if zero-coefficient logits or direct cache-tensor comparisons fail. A lower coefficient that removes `social` collapse but retains held-out concept movement would change the verdict for the edit rule, not retroactively validate job 1704.

### Recommended sequence
