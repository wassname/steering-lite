# Research: Jev judge API audit

## Summary
All five `judge.py` questions use valid types and request shape. Biggest risks are contradictory rubric language and interpreting ordinal score differences as calibrated effect sizes.

## Findings
1. **Documented schema.** OpenRouter specifies “Decisions API | `POST https://openrouter.ai/api/alpha/decisions`” and lists **Choice, Noul, Score**—no dedicated pairwise/rank/boolean/probability *type*. [OpenRouter](https://openrouter.ai/docs/guides/community/jev). TypeSafe requires `model`, `state` (string/object/array), and named `questions` with `type`, `instructions`, `criteria`: Choice uses option→description (maximum **255**); Score an ordered array of **2–10** levels; Noul optional `true`/`false` descriptions, returning P(yes). Quote: Score returns “a probability-weighted value across your levels.” [TypeSafe API](https://docs.typesafe.ai/api.md). Direct pairwise comparison can instead use Choice `{A_more, B_more, same/unclear}` (inference).

2. **Nine levels, order, arithmetic.** TypeSafe: “The order of the array is the numbering”; numbering begins at **0**. “The model gets the descriptions and nothing else, and each level is judged on its own against the state.” Score equals “each level number multiplied by its probability, added up.” Levels should describe one concrete dimension. [Score guide](https://docs.typesafe.ai/primitives/score.md). Nine PREMISE levels satisfy the limit; order and wording matter. The [sample](file:///workspace/2026/lite/steering-lite-bsbench/slop/reviews/2026-09-25_jev_switch/sample_records.json) premise `.01` matches `.99×0 + .01×1`; damage `.19` versus `.18` from *rounded displayed* probabilities plausibly reflects hidden precision, not a proven bug.

3. **Five questions ([local implementation](file:///workspace/2026/lite/steering-lite-bsbench/scripts/bsbench/judge.py); assessment is inference).** `premise`: valid Score 0–8, but correction versus practical inability at levels 0–2 and praise **plus** acceptance at level 8 mix dimensions. `damage`: valid Score 0–4, but instructions call vagueness **severe** while levels 1/2 explicitly classify vagueness minor/clear and level 3 describes incoherence/repetition; reconcile. `stance_A`/`stance_B`: valid four-way Choices including `no_answer`; both nevertheless see both answers in shared state, so not isolated ratings. `concept`: valid 11-way Choice including `none`, but sycophancy, verbosity, hedging and degradation may coexist; one winner hides mixed changes. TypeSafe recommends `other`/`none` when options do not cover every input. [Choice guide](https://docs.typesafe.ai/primitives/choice.md).

4. **Confidence, stability, price, limits.** TypeSafe: confidence “is a statistic computed from the probability distribution”; it neither certifies correctness nor equals winning probability. [Confidence](https://docs.typesafe.ai/confidence.md). OpenRouter says “Your probabilities will differ slightly from run to run”: the script’s deterministic docstring is unsupported. No temperature field appears in the [request reference](https://docs.typesafe.ai/api.md). [OpenRouter model](https://openrouter.ai/typesafe/jev-1.13): **32k context, $0.042/M input tokens, free output**. TypeSafe direct-model limits differ (64k total batched, 32k state + longest question); use OpenRouter’s 32k conservatively. [Models](https://docs.typesafe.ai/models.md). TypeSafe recommends “narrow, typed questions with explicit instructions and criteria.” [Prompting](https://docs.typesafe.ai/concepts/how-to-build-with-system-one.md).

5. **Misleading numbers.** TypeSafe: “Please do not use score outputs ... to compute the exact magnitude of a number between two levels”; thresholding the expectation is permitted. [Jaggedness](https://docs.typesafe.ai/model-jaggedness/jev-1.13.md). Premise subtraction, absolute damage differences and 1.5 cutoff are **ordinal proxies**, requiring human-label validation (inference). Sample concept winner `verbose` gets `.51` versus `.25` for `sycophantic`: winner-only reporting hides uncertainty. Dated snapshot `typesafe/jev-1.13-20260917` and `usage.cost` are expected. [Tutorial](https://openrouter.ai/docs/guides/community/jev-tutorial).
